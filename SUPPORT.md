# Getting support for Kinloom

Use the right channel below so maintainers and community members can help you quickly.

## Before you ask

- Review [README.md](README.md) for quickstart commands, package responsibilities, and plugin seams.
- Explore the live public-domain demo at [https://tiberriver256.github.io/kinloom/](https://tiberriver256.github.io/kinloom/).
- Run `npx kinloom guide` to read the 26 built-in archival research and operator guides.
- Read [DESIGN.md](DESIGN.md) for Paper & Ink design tokens, [docs/observability.md](docs/observability.md) for telemetry, and [docs/colab-gpu-tts.md](docs/colab-gpu-tts.md) for GPU narrative audio synthesis.

## Privacy reminder

Never post living relatives' personal names, birth dates, addresses, GEDCOM files, or private scans in public issues or discussions. Reproduce problems with synthetic names or records from `examples/demo/`.

## Where to go

| Need | Channel |
| --- | --- |
| Questions about setup, Cloudflare deployment, GEDCOM slicing, or workflows | [GitHub Discussions (Q&A)](https://github.com/Tiberriver256/kinloom/discussions/categories/q-a) |
| Share a self-hosted archive setup, custom plugin, or research workflow | [GitHub Discussions (Show and tell)](https://github.com/Tiberriver256/kinloom/discussions/categories/show-and-tell) |
| Discuss roadmap ideas or open-ended proposals | [GitHub Discussions (Ideas)](https://github.com/Tiberriver256/kinloom/discussions/categories/ideas) |
| Report a reproducible bug, request a concrete feature, or propose a plugin seam | [GitHub Issues](https://github.com/Tiberriver256/kinloom/issues/new/choose) |
| Report a security vulnerability or living-person privacy bypass | [Private GitHub Security Advisory](https://github.com/Tiberriver256/kinloom/security/advisories/new) (see [SECURITY.md](SECURITY.md)) |
